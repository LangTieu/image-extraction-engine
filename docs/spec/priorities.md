# Priorities (P0)

Mapping of requirements to release priorities, per the development plan.

## P0 - Must have (MVP core)

- OCR + preprocessing pipeline
- Table extraction preserving row/column structure
- Data validation with confidence and review flags
- Excel (XLSX) and JSON export

## P1 - High

- Industrial HMI parser
- Configurable coil schema (per-factory profiles of the industrial field dictionary)
- Confidence scoring and manual review workflow

## P2 - Medium

- Vision AI integration (Qwen2.5-VL local; Gemini Vision opt-in only - see privacy.md)
- Web UI
- API access
- Batch processing

## P3 - Later

- Database-backed job history
- Automation and scheduled runs
- Advanced analytics
- Downstream integrations
